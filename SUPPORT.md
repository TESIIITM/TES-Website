# Getting help

- **Found a bug?** [Open a bug report](https://github.com/TESIIITM/TES-Website/issues/new?template=BUG_REPORT.yml).
- **Have an idea?** [Open a feature request](https://github.com/TESIIITM/TES-Website/issues/new?template=FEAT_REQUEST.yml).
- **Stuck while contributing?** Ask in your issue or PR and tag [@dhananjay-123](https://github.com/dhananjay-123).
- **Security problem?** See [SECURITY.md](SECURITY.md). Please don't post it publicly.
- **Questions about TES, events, or joining?** Email [tes@iiitm.ac.in](mailto:tes@iiitm.ac.in) or message [@tes_iiitm](https://www.instagram.com/tes_iiitm) on Instagram.
- **Want something changed on the site** (members, announcements, links)? That's done in the admin dashboard, so ask a society maintainer.

It helps to check the [README](README.md), [CONTRIBUTING.md](CONTRIBUTING.md), and [existing issues](https://github.com/TESIIITM/TES-Website/issues) first. We're all students doing this in our free time, so please be patient.
